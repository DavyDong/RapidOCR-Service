# Upstream workflow reference

These files are unchanged workflows from RapidAI/RapidOCR at base commit
`7cfd3d9ef786a2e538ca30df700325e72e85b5f5`. They retain the upstream Apache-2.0
terms and are kept here as documentation, outside `.github/workflows/`.

They target upstream publishing, synchronization, notifications and star tracking,
not this service. They must not be enabled for this repository without adapting
their destinations, permissions and credentials. No workflow runs from this
directory.
